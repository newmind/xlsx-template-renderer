# 이벤트 시트 복사 및 렌더링 스크립트 구현

## 동작 흐름

```mermaid
flowchart TD
    A[data.json 로드] --> B[events를 event_name 기준 그룹화]
    B --> C{그룹별 반복}
    C --> D[story-template 시트 복사]
    D --> E[시트명 생성]
    E --> F[해당 시트 렌더링]
    F --> C
    C --> G[story-template 시트 삭제]
    G --> H[output.xlsx 저장]
```

## 시트명 생성 규칙

- **단일 이벤트**: event_title 그대로 (예: "1부 대면 팬사인회")
- **복합 이벤트**: event_title들 조합 (예: "1부 대면 팬사인회 2부 포토회")
