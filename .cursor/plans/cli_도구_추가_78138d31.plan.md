# CLI 도구 추가 계획

## 목표

`xlsx-render` 명령으로 템플릿을 렌더링할 수 있는 CLI 도구 추가

## 사용법 예시

```bash
# 출력 파일 지정
xlsx-render input.xlsx data.json -o output.xlsx

# 특정 시트만 렌더링
xlsx-render input.xlsx data.json --sheets Sheet1 Sheet2 -o output.xlsx

# in-place 렌더링 (경고 표시 후 확인)
xlsx-render input.xlsx data.json
# → "경고: input.xlsx 파일이 직접 수정됩니다. 계속하시겠습니까? [y/N]"
```

## 구현 내용

### 1. CLI 모듈 생성

- 파일: `src/xlsx_template_renderer/cli.py`
- 표준 라이브러리 `argparse` 사용 (의존성 추가 없음)
- 파라미터:
  - `template` (필수): 입력 xlsx 파일 경로
  - `data` (필수): JSON 데이터 파일 경로
  - `--sheets`, `-s` (옵셔널): 렌더링할 시트 이름들 (여러 개 가능)
  - `--output`, `-o` (옵셔널): 출력 파일 경로
  - `--yes`, `-y` (옵셔널): in-place 확인 프롬프트 건너뛰기

### 2. 핵심 로직

```python
def main():
    args = parse_args()
    
    # JSON 데이터 로드
    data = json.load(args.data)
    
    if args.output:
        # 출력 파일이 이미 존재하면 덮어쓰기 확인
        if Path(args.output).exists() and not args.yes:
            print(f"경고: '{args.output}' 파일이 이미 존재합니다.")
            confirm = input("덮어쓰시겠습니까? [y/N]: ")
            if confirm.lower() != 'y':
                print("취소되었습니다.")
                sys.exit(0)
        render_template_to_file(args.template, args.output, data, args.sheets)
    else:
        # in-place 렌더링 → 경고 후 확인
        if not args.yes:
            print(f"경고: '{args.template}' 파일이 직접 수정됩니다.")
            confirm = input("계속하시겠습니까? [y/N]: ")
            if confirm.lower() != 'y':
                print("취소되었습니다.")
                sys.exit(0)
        render_template(args.template, data, args.sheets)
```
