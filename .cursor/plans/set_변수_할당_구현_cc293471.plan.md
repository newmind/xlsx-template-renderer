# set 변수 할당 기능 구현

## 구현 범위

**포함:**

- 단순 변수 할당: `{% set var = value %}`
- 딕셔너리 리터럴: `{% set types = {"a": "대면사인회", "b": "포토"} %}`
- 딕셔너리 접근: `{% set name = types[key] %} `또는 `{% set name = types.get(key, "기타") %}`
- 인라인 if: `{% set name = "대면사인회" if type == "a" else "포토" %}`

**제외 (Jinja2 고급 기능):**

- 블록 할당: `{% set var %}...{% endset %}`
- namespace 객체
- 다중 변수 언패킹: `{% set a, b = tuple %}`

## 1. parser.py 수정

### TokenType 추가

```python
class TokenType(Enum):
    ...
    SET = auto()  # {% set var = value %}
```

### 패턴 추가

```python
SET_PATTERN = re.compile(r'^set\s+(\w+)\s*=\s*(.+)$')
```

### Token 필드 추가

- `set_var`: 할당할 변수명
- `set_value`: 할당할 표현식

### _parse_control_statement() 수정

- `{% set var = value %}` 파싱 추가

### is_control_statement() 수정

- set 문도 control statement로 인식

## 3. renderer.py 수정

### _process_rows() 수정

`TokenType.SET` 처리 추가:

```python
elif token.type == TokenType.SET:
    value = evaluate_expression(token.set_value, context)
    context[token.set_var] = value
    row_idx += 1
    continue  # set 행은 출력에 포함하지 않음
```

**주의:** context를 직접 수정하므로 for 루프 등에서 생성한 loop_context에도 영향을 줌

### docs/SYNTAX.md

"제어문" 섹션에 `set 변수 할당` 추가 (if 조건문 다음에 위치):

```markdown
#### set 변수 할당

템플릿 내에서 변수를 정의합니다.

{% set 변수명 = 값 %}

**기본 사용:**
{% set discount = 0.1 %}
{% set message = "안녕하세요" %}

**딕셔너리 매핑:**
{% set event_types = {"a": "대면사인회", "b": "포토", "c": "게임회"} %}
{% set event_name = event_types.get(event_type, "기타") %}

**조건부 할당 (인라인 if):**
{% set status_text = "완료" if is_done else "진행중" %}

**스코프 규칙:**
- if 블록 내에서 설정한 변수는 외부에서도 접근 가능
- for 루프 내에서 설정한 변수는 루프 외부에서 접근 불가
```

### 스코프 설명 상세

**if 블록 (스코프 없음):**

```
{% if status == "active" %}
{% set label = "활성" %}
{% else %}
{% set label = "비활성" %}
{% endif %}
{{ label }}  ← 정상 출력됨
```

**for 루프 (스코프 있음):**

```
{% for item in items %}
{% set found = true %}
{% endfor %}
{{ found }}  ← undefined (접근 불가)
```

이 동작은 Jinja2의 표준 스코프 규칙을 따릅니다.

## 다른 제어문과 함께 사용

### for 루프에서 set 변수 사용

```
{% set categories = {"A": "전자제품", "B": "의류", "C": "식품"} %}
{% for item in items %}
{% set category_name = categories.get(item.category, "기타") %}
| {{ item.name }} | {{ category_name }} | {{ item.price }} |
{% endfor %}
```

### if 조건문에서 set 변수 사용

```
{% set discount_rate = 0.1 if is_member else 0 %}
{% if discount_rate > 0 %}
| 할인율 | {{ discount_rate * 100 }}% |
{% endif %}
| 최종가격 | {{ price * (1 - discount_rate) }} |
```

### set으로 조건 분기 단순화

```
{% set event_types = {"a": "대면사인회", "b": "포토", "c": "게임회"} %}
{% set event_name = event_types.get(event_type, "기타") %}
{% if event_name != "기타" %}
| 이벤트 유형 | {{ event_name }} |
{% else %}
| 이벤트 유형 | 미정 |
{% endif %}
```

## 사용 예시

```
A1: {% set event_types = {"a": "대면사인회", "b": "포토", "c": "게임회"} %}
A2: {% set event_name = event_types.get(event_type, "기타") %}
A3: 이벤트: {{ event_name }}
```

또는 인라인 if 사용:

```
A1: {% set event_name = "대면사인회" if event_type == "a" else "포토" if event_type == "b" else "게임회" %}
A2: 이벤트: {{ event_name }}
```
