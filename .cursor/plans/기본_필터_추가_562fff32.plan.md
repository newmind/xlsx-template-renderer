# 기본 필터 11개 추가

기존 `@register_filter` 데코레이터 패턴을 활용하여 새로운 필터들을 추가합니다.

## 변경 파일

### 1. [src/xls_template_renderer/filters.py](src/xls_template_renderer/filters.py)

기존 `filter_join` 함수 아래에 11개 필터 추가:

| 카테고리 | 필터 | 설명 |

|----------|------|------|

| 문자열 | `upper` | 대문자 변환 |

| 문자열 | `lower` | 소문자 변환 |

| 문자열 | `title` | 제목 케이스 변환 |

| 숫자 | `round` | 반올림 (precision 인자 지원) |

| 숫자 | `abs` | 절대값 |

| 숫자 | `int` | 정수 변환 |

| 숫자 | `float` | 실수 변환 |

| 문자열 | `trim` | 앞뒤 공백 제거 |

| 문자열 | `replace` | 문자열 치환 |

| 리스트 | `first` | 첫 번째 요소 |

| 리스트 | `last` | 마지막 요소 |

### 2. [tests/test_filters.py](tests/test_filters.py)

각 필터에 대한 테스트 클래스 11개 추가

### 3. [docs/SYNTAX.md](docs/SYNTAX.md)

필터 테이블 확장 (134-147 라인 근처):

```markdown
| 필터 | 설명 | 예시 |
|------|------|------|
| `default(값)` | None일 때 기본값 반환 | `{{ value\|default('N/A') }}` |
| `length` | 길이 반환 | `{{ items\|length }}` |
| `join(구분자)` | 리스트를 문자열로 연결 | `{{ items\|join(', ') }}` |
| `upper` | 대문자 변환 | `{{ name\|upper }}` |
| `lower` | 소문자 변환 | `{{ name\|lower }}` |
| `title` | 제목 케이스 변환 | `{{ name\|title }}` |
| `round(정밀도)` | 반올림 | `{{ price\|round(2) }}` |
| `abs` | 절대값 | `{{ value\|abs }}` |
| `int` | 정수 변환 | `{{ num\|int }}` |
| `float` | 실수 변환 | `{{ num\|float }}` |
| `trim` | 앞뒤 공백 제거 | `{{ text\|trim }}` |
| `replace(old, new)` | 문자열 치환 | `{{ text\|replace('a', 'b') }}` |
| `first` | 첫 번째 요소 | `{{ items\|first }}` |
| `last` | 마지막 요소 | `{{ items\|last }}` |
```
